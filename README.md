# À propos de moi


Je suis **Développeur Full Stack Web & Mobile** spécialisé dans la création d'applications évolutives, de plateformes SaaS et de solutions intelligentes. En dehors du code, je suis passionné de jeux vidéo, de musique et d'animés. Ces univers nourrissent ma créativité et m'aident à penser le design différemment, avec plus d'émotion et d'attention aux détails.


Mon objectif est de transformer des problèmes métiers complexes en solutions logicielles modernes, performantes et sécurisées.


Je développe principalement :


- Plateformes SaaS modernes
- Applications web performantes
- Applications mobiles multiplateformes
- Systèmes de gestion métier
- Tableaux de bord analytiques


Je suis passionné par :


- Architecture logicielle
- Développement Back-End
- Intelligence Artificielle
- Agents IA
- Cybersécurité
- Data Engineering
- Prompt Engineering
- Cloud Computing


Ma vision du développement :


> Un excellent logiciel combine une architecture solide, une expérience utilisateur fluide, une excellente qualité de code et une vraie réponse aux besoins utilisateurs.

Chaque projet que je développe suit une approche basée sur :

<tr>


<td width="50%">

<td width="50%">

</td>


</tr>



<tr>


<td width="50%">

</td>

- Requêtes efficaces

</td>


</tr>

Mon objectif est de construire des produits :

> fiables, maintenables, évolutifs et capables d'apporter une vraie valeur.
